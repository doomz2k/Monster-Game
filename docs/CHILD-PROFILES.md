# Separate adventures

**Start → Adventures on this device** lets a parent add, name and open up to four adventures. Each keeps its own monster, clothes, stars, home, garden, collections, preferences, tutorial and practice record. New adventures start fresh. Creating one adds a card; opening it is a separate action that saves the current adventure and reloads the welcome screen, clearing the previous world's transient activity state.

The original adventure retains its exact existing primary and backup keys. Additional adventures have separate, strictly bounded storage namespaces and three independent recovery copies. The active selection and labels use a small local index. Names are limited to 24 characters and remain in the browser; they are not sent for speech generation. Additional adventures use a new generic British welcome recording. Recording approvals and master mute remain shared device controls, as explained in the parent panel.

Save export/import and recovery now operate on the current adventure's namespace. Each adventure can be exported independently as `monster-adventure-save.json`. No stored adventure is automatically deleted. If a profile-list write fails after a new save was created, reading the known namespaces recovers that card rather than overwriting it for another child. Bad metadata cannot escape the four known namespaces or write to the shared sound-review keys.

Opening another adventure validates the target and saves current progress before changing the active selection. A quota failure leaves the active selection unchanged. Recovery only uses that child's copies. A damaged secondary adventure falls back to the original when it can be opened, preserving the damaged files. If the original cannot be read or recovered, autosaving stays paused; explicit recovery can re-enable it. This prevents a temporary fresh screen from overwriting unreadable stored progress.

The browser walkthrough added a local test adventure, verified zero practice records, changed its music to 20%, renamed it, opened the original again and verified the original 69 stars, 17 practice records and 35% music remained. No new runtime warnings were reported. Recovery replacement was tested in isolated storage; the earlier live-restore restriction documented in COMFORT-AND-RECOVERY remains respected.

Type checking, lint and production build pass. Narration now has 564 technically checked British files; listening and phonics specialist approval remain outstanding.
