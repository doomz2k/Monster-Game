# 50 further enhancements for Monster & Friends

These are proposals beyond this release, not claims that the features already exist. Priorities balance presentation, depth and replayability for a four-year-old. **P1** establishes a dependable, enjoyable core; **P2** adds lasting variety; **P3** expands the world after the core is proven. Avoid timers, lost rewards, daily streak pressure and reading-dependent navigation.
