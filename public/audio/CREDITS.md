# Audio provenance

Imported from the user's [clover-games repository](https://github.com/doomz2k/clover-games) at commit `51869d01a4e0efc12bc1982b63064bd6caddff3b`, as authorised for use in this game.

- `phonemes/*.ogg`: selected `voices/lab/<token>__live.ogg` snapshots. These are unverified candidates, not official Read Write Inc. recordings. None is enabled for teaching by default.
- `narration/*.ogg`: selected number and whole-word clips, mapped by `lib/audio-data/narration.json` in the source repository. The original voice pipeline identifies Piper and the British English `en_GB-cori-high` voice for narration. No voice model is distributed here.
- `lib/audio-data/phonemes.json` in the source repository includes the original repository's historical Wikimedia source references where available. The original pipeline could later override live files with generated candidates, so these references are provenance leads, not proof of the present clip's source or quality.

No Ruth Miskin/Oxford University Press video or publisher-owned audio has been extracted or redistributed. The official parent films are linked for reference.

Sound effects in the new game are generated by its Web Audio code. Imported personal sound recordings stay in the user's browser and are not sent to the server.
